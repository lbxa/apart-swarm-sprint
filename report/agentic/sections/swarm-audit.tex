\subsection{Reproduce the frozen tables}
Use the verified original evidence packet, not the dashboard's headline
counters. The W\&B \texttt{cases} summary entry is a table object, and default
session uploads omit raw \texttt{.calls.jsonl} records. The selected S1
per-call quotations were checked against separately retained local bytes;
their complete locators are in \path{report/agentic/trace-sources.md}.

\begin{quote}\small
\begin{verbatim}
python3 -I report/analysis/swarm_track_snapshot.py \
  --evidence-root /path/to/verified-evidence \
  --registry report/data/swarm-track-snapshot.json \
  --output report/data/swarm-track-snapshot.json \
  --tables report/tables
\end{verbatim}
\end{quote}
Then run \texttt{make -C report agentic}. The snapshot has
\SnapshotTotalFalse{} false reveals, \SnapshotTotalTruthful{} truthful reveals,
\SnapshotTotalAbstained{} abstentions and \SnapshotTotalUnrevealed{}
unrevealed commitment across all conditions. These totals combine different
interventions and are not an aggregate collusion statistic. Per-case records
preserve the variation and the dependence within repeated-exposure blocks.
