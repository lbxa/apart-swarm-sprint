\section{What can we infer about network shape?}
The current data answer part of the track question: exposed bad behavior can
be adopted, reach multiple evaluated jurors and capture a collective decision
within one case. They do \emph{not} identify whether a ring, hub or modular
network spreads that behavior differently. We have no otherwise matched
communication graphs with different shapes. A shared public forum gives the
seeded bloc direct access to all evaluated jurors; observed private-message
paths are endogenous choices, not randomized topology treatments.

The network's \emph{decision rule} does give a useful analytical result. In
every primary colluding-peer condition, $q-m=1$: one evaluated adopter can
change the verdict. A larger seeded bloc can therefore capture a larger jury
without requiring a longer transmission chain. Jury size, seed count, seed
fraction, modeled population and the inducement-to-ordinary-reward ratio all
change together. A trend across sizes could reflect any of them, or increased
non-participation. It cannot be assigned to network shape or to scale alone.

The repeated-exposure arm likewise changes temporal continuity, not spatial
connectivity. It reuses the same jurors and supplies the adversarial example
again. Neither persistence across cases nor a model-generated recruiting
message proves transmission from an initially compromised node to an
otherwise unexposed second generation.

\subsection{A topology comparison that would identify the missing effect}
The next experiment should hold seven jurors, one scripted bad juror, model,
charter, payment schedule, opportunity budget and evidence fixed. Unlike the
present near-majority bloc, this leaves three additional false votes needed
for capture. Randomize the permitted deliberation graph and initial seed
location. A seven-node ring and a seven-edge hub-dominated graph provide an
equal-edge-count comparison; a complete graph can serve as a separate dense
reference. Treat hub versus peripheral seeding as an explicit factor.

Turn off unrestricted public deliberation and enforce those communication
edges at the gateway; otherwise the forum bypasses the manipulated graph.
Keep the factual case equally accessible. Include a matched no-bad-peer
control with the same publisher incentive to measure adoption from the offer
alone. Supply the adversarial seed once, rather than reintroducing it every
round. Deliver messages in logical rounds so every forwarding event and first
exposure has a recorded position independent of provider latency.

For a clean single-source version, make the publisher and challenger passive
case fixtures and replace publisher recruiting messages with a common fixed
payment rule. Only the seeded juror then supplies adversarial deliberation.
This changes the current non-escrowed offer mechanism and needs a calibrated
positive control before the topology comparison.

Measure first false commitment and confirmed reveal by round, number of newly
adopting agents, maximum reached distance from the seed, persistence, missing
votes and capture. Keep an entire independently initialized run as the unit
of replication; determine the number of runs from a declared precision or
power target. A forwarded message establishes an exposure edge; it still needs
a subsequent action to establish behavioral adoption. This design is proposed
and has not been run. It is the missing intervention needed for a network-shape
claim, not a result inferred from the current size comparison.

\section{Conclusion}
Seeded financial recruitment can turn an acknowledged falsehood into a
contract-valid, paid collective verdict in selected Kimi runs. The evidence
connects an adversarial example to stated rationale, binding actions and
payment, while preserving honest-peer controls, explicit-duty nulls and
non-participation. It establishes direct reach and repeated-case persistence
under the tested conditions. Network-shape effects and multi-hop transmission
speed remain unidentified; the report's contribution is an auditable result
and a concrete experiment that separates those questions.
