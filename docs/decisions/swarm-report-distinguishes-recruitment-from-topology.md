# Swarm report distinguishes recruitment from topology

- **Date:** 2026-11-09
- **Status:** Accepted
- **Deciders:** Lucas Barbosa
- **Area:** report, research methods, evidence admission

## Context

Lucas selected the Swarm Alignment Hackathon's question about how fast and how
far bad behavior spreads from a compromised agent and whether network shape
matters. The current campaign changes jury size and seeded-bloc size together;
all evaluated jurors receive the same public recruitment attempt. The existing
report instead centered a pre-sprint endogenous-funding study.

## Decision

Center the current report on direct recruitment, reach and repeated exposure,
using a frozen cloud artifact audit. Preserve the previous narrative as
`report/agentic/historical-main.tex`. Explicitly state that the current design
does not identify a network-shape effect or multi-hop infection speed, and
describe a matched graph experiment as proposed work.

## Consequences

- At the 2026-11-09 05:53 UTC cutoff, 72 matching W&B sessions yield 71 admitted
  sessions and 83 cases. One setup-only exclusion has no play; all seven played
  failures remain. Two missing manifest episode arrays are recovered from
  retained case evidence. No selective reruns or new model calls are performed.
- The two checkout cohorts have identical retained runtime source hashes and
  per-cell configurations after path/seed normalization. Combined counts are
  descriptive; cohort and run identities remain in the snapshot. Repeated seed
  labels do not become extra distinct seeds.
- A false reveal is an executed factual decision, not automatically proof of
  a coalition or faithful intent. The short charter omits truth/independence
  duties. The report retains paid coordination against the truth as its label
  for the source-pinned positive example.
- The `contagion` configuration is presented as repeated exposure because it
  re-supplies the scripted offer and peer in every case. It does not isolate
  memory, prior payment or multi-hop transmission.
- Shared public deliberation prevents a topology comparison. Larger juries
  increase seed dose and change reward shares while retaining `q-m=1`; size
  differences cannot be assigned to shape or scale alone.
- Earlier narrative counts are reconciled against retained evidence. The
  fifty-session principles packet and committed snapshot give 390 truthful
  reveals and ten abstentions, not the handoff's 397. The report uses the
  reproducible count and records the discrepancy without rewriting old records.
- Current venue requirements replace the October target. Visual equivalence
  with the new official Google Docs template and author affiliations remain
  open; the result is an internal draft, not a submitted or certified PDF.

## Alternatives considered

Calling the size comparison a topology experiment would overstate its
identification. Calling the repeated-case block a demonstrated contagion
mechanism would ignore re-seeding and common payment offers. Keeping the
October narrative central would obscure the work relevant to the selected
November research track.
