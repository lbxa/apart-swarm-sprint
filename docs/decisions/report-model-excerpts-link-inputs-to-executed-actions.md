# Report model excerpts link inputs to executed actions

- **Date:** 2026-11-09
- **Status:** Accepted
- **Deciders:** Lucas Barbosa
- **Area:** report, research evidence

## Context

Lucas requested adapting a supplied LaTeX prompt/response template to the
research report, with actual model output and returned reasoning in both the
main text and appendix. Outcome summaries alone conceal the contrast between
acknowledged facts, a payment proposal, the assessment submitted and the
executed vote. The manuscript covers the historical October agentic campaign;
the available completed Kimi case uses a separate seeded-peer protocol.

## Decision

Include labeled, source-pinned excerpts in the existing manuscript's typography,
with a compact results vignette and a contextual appendix. Distinguish scripted
inputs, public model statements, provider-returned reasoning, action requests
and confirmed execution; keep researcher interpretation outside quote panels.

## Consequences

- The selected Kimi case is separately scoped and is not pooled with the
  original campaign or used to estimate incidence. The short charter's omitted
  truth/independence duties cannot be violated; this is paid coordination
  against the truth.
- Returned reasoning supports an observable stated rationale, not guaranteed
  access to faithful internal computation. Quotes preserve mistakes and mark
  omissions. Executed reveals and transfers supply behavioral evidence.
- The user template supplies structure, not fabricated examples or a new page
  layout. Breakable panels retain Times fonts and the report's blue palette.
- Selected excerpts enter the report source under this user request. Complete
  raw trajectories, private conversations and credentials remain excluded.
  The [source register](../../report/agentic/trace-sources.md) pins original
  bytes and records missing historical source access and open human review.
- The appendix adds length. Venue visual compliance and independent human
  semantic review remain open; this remains an internal draft.

See [the evidence guide](../reporting/writing.md#make-the-reasoning-inspectable),
[the report](../../report/agentic/main.tex), and
[the claim mapping](../reporting/paper-brief.md).

## Alternatives considered

Outcome-only tables omit the requested textual evidence. Unlabeled transcript
dumps blur supplied recruitment with evaluated behavior and make provenance
harder to inspect. Neither supplies the requested readable evidence sequence.
