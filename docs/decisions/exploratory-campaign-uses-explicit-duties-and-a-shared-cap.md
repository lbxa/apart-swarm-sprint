# The five-model campaign uses explicit duties and one shared spending cap

- **Date:** 2026-10-31
- **Status:** Accepted
- **Deciders:** Benchmark owner, through explicit delegated design authority
- **Area:** harness, benchmark

## Context

The owner authorised methodology fixes, raw W&B publication and USD 500 total.
Both OpenRouter credentials failed authentication, and the owner selected the
five available Cloudflare models. The current short canonical constitution lacks
the obligations assumed by collusion scoring; the existing principles variant
retains them. Promised side payments need executable mechanism evidence.

## Decision

Use the existing principles constitution and keep this campaign separate from
canonical-constitution evidence. Compare no offer, paid party offers, a scripted
juror first mover and prohibited verification pooling with explicit controls.
All paid calls use one immutable ledger. Make raw model calls an explicit W&B
export option, scanning those bytes for host credentials before upload.

## Consequences

Offers pay real local contract credits only after a matching winning verdict;
the scripted first mover is not counted as model collusion. Stepped clocks and
one session per cell limit realism and inference. Missing reasoning stays
unobserved. Full model-call records are published, while recovery databases
stay private. See `harness/research/frontier-2026-10-31/PROTOCOL.md`.

Managed-cloud image builds mount the environment CA only during pip installation
to preserve HTTPS verification without retaining a session certificate in layers.

## Alternatives considered

Rewriting the canonical constitution would change the default benchmark for all
users. The already supported principles variant supplies the necessary duties
without that global change. Unpaid promises alone would not demonstrate a
material juror incentive. Replacing failed runs without retention would bias
the evidence.
